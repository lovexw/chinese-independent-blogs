# 博客评分标准（docs/scoring.md）

> 2026-10-11 起生效。给每个收录博客一个 1-100 的质量分，作为维护者控制列表质量的标尺：
> **任何新收录默认 60 分基准线**，之后按可量化信号（每周巡检自动刷新）与人工评定不断升降。
> **≥80 分的博客在前台优先推荐**（默认排序置顶 + ★ 徽标），**≥90 为精选**。

## 分数构成

```
最终分 = manual.score                    （人工绝对分，优先级最高）
       或 clamp(1, 100, 60 + 自动分 + manual.delta)   （人工微调）
       或 clamp(1, 100, 60 + 自动分)      （无人工因素）
```

- 数据文件：`data/scores.json`（key = hostKey，去 `www.` 的主机名）。
- 自动部分由 `scripts/score-refresh.mjs` 每周巡检刷新（约 1 分钟，含全站 TTFB 测速）；
  人工部分（`manual` 字段）**永久保留**，刷新不会覆盖。
- 后台打分入口：博客管理页 → 点击评分徽章（或审核上架时直接给初始分）。

## 自动评分维度（60 分基准上加减）

| 维度 | 分值 | 数据来源 | 说明 |
| --- | --- | --- | --- |
| 更新频率 | +14 / +12 / +9 / +6 / +2 / -6 / -12 | `data/lastupdate.json` 内容级最近更新 | 近 7 天 / 30 天 / 90 天 / 半年 / 一年 / 沉睡 1-2 年 / 沉睡 2 年+；未知不奖不罚 |
| 订阅完备 | +2 / 0 | CSV RSS 字段 | 提供 RSS 订阅 |
| 打开速度 | +4 / +3 / +1 / -2 / -4 / -5 | 巡检时实时 TTFB 测速 | ≤300ms 秒开 / ≤800 / ≤2s / ≤4s / >4s / 超时失败 |
| 可达性 | -15 / 0 | `data/check-results.json` | 巡检判定不可达；401/403/429 等"反爬但存活"保留类**不罚** |
| 读者热度 | +4 / +3 / +2 | `data/stats.json` 外链点击 | 近 90 天列表页点击 TOP10 / TOP50 / TOP150（读者用点击投票） |

自动分满配 = 60 + 14 + 2 + 4 + 4 = **84**：一个活跃、有 RSS、秒开、有读者的博客可以自然爬到推荐档。

## 人工评定（维护者主观因素）

- 知名经典博客直接定 **90-100**（首批：阮一峰 98、酷壳 97、云风 95、新的原野 95、DIYGod 94、王垠 93、张鑫旭 93、可能吧 92、Matrix67 92、MacTalk 90 等）。
- 机器刷活跃、内容注水的在后台手动调低（自动分故意**不对** machine-scan 的 cron 指纹自动扣分——2026-10-11 实测 8 个 cron 命中全为人类定时发布，误杀率高，交人工判断）。
- 「恢复自动分」= 清除人工评定，交回算法。

## 档位与前台行为

| 档位 | 分数 | 后台徽标 | 前台行为 |
| --- | --- | --- | --- |
| 精选 | ≥90 | 金色 ★ | 默认排序最前（限活跃站），卡片带 ★ 徽标 |
| 推荐 | 80-89 | 绿色 | 同上，默认排序随精选块 |
| 基准 | 60-79 | 灰色 | 正常排序 |
| 待观察 | <60 | 琥珀色 | 正常排序；持续沉睡/不可达会继续下沉 |

默认排序（"编辑推荐排序"）：**推荐块（≥80 且活跃，块内按评分降序）→ 活跃 → 沉睡 2 年+ → 更新时间未知**；
另有独立排序项"评分优先"（纯评分降序）。沉睡的精选博客保留 ★ 徽标但不进推荐块（避免陈年经典霸占活跃位）。

## 新收录流程

1. 后台审核通过时可直接填初始分（默认 60），写入 `data/scores.json` 并随收录一起提交 git。
2. 下一轮每周巡检自动补充自动信号明细（`auto`/`autoDetail`/`signals`）。
